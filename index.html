1. What is an Interaction Net?

Introduced by Yves Lafont in 1990 (Interaction Nets, POPL '90), an interaction net is a graph-rewriting model of computation where nodes are agents with fixed arity and edges are wires. Every agent has 1 principal port (drawn as the top ▲ apex) and n auxiliary ports (drawn along the bottom arc, numbered 1..n).

Reduction happens only when two agents meet principal-port-to-principal-port (A >< B), forming an active pair. Because at most one rule exists for any pair of agent types and rules only rewrite active pairs locally, reduction satisfies strong confluence: firing active pairs in any order—or all non-overlapping pairs simultaneously via Step All—always yields the exact same normal form.

2. Assembler Syntax

# 1. Declare agent types: agent <Name> <Arity>
agent ε 0        -- principal port only
agent γ 2        -- principal + 2 auxiliary ports

# 2. Declare symmetric interaction rules:
rule γ(x1, x2) >< γ(y1, y2):
  x1 ~ y1
  x2 ~ y2

rule ε() >< γ(x1, x2):
  ε() ~ x1
  ε() ~ x2

rule ε() >< ε():
  -- nothing (both vanish)

# 3. Wire the initial net:
net main:
  γ(a, b) >< γ(c, d)
  a ~ c
  b ~ d

3. Wiring & Validation Rules

• A(x1, ..., xn) >< B(y1, ..., ym) connects the principal ports of A and B directly.
• A(x1, ..., xn) ~ w connects the principal port of A to wire w.
• w1 ~ w2 fuses wire w1 with wire w2.
• Result(out) attaches wire out to auxiliary port 1 of a root collector agent.
• Strict Linear Wire Check: Every wire name in a rule (header + body) or net must appear exactly twice.
